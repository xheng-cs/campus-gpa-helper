# campus-gpa-helper
GPA+ 校园学业助手是一个零依赖、打开即用的网页小工具，面向大学生日常的绩点与学业管理场景。它支持 4.0 分档制与 5.0 连续制两种绩点算法一键切换，成绩可输入百分制或等级制（优秀/良好/中等/及格/不及格），可添加删除课程并实时计算总学分、加权平均分与 GPA；同时提供带截止日期的作业待办清单，过期任务自动高亮。数据全部保存在浏览器 localStorage 中，无需注册、无需联网、刷新不丢。技术上前端使用原生 HTML/CSS/JavaScript，采用纯函数计算核心与 UI 层分离的设计，核心逻辑配备 12 个单元测试，并通过 GitHub Actions 实现推送即自动测试的持续集成。
