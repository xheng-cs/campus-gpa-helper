# 🎓 GPA+ 校园学业助手

零依赖、打开即用的校园学业小工具：**绩点计算 + 课程管理 + 作业待办**。
数据只保存在你的浏览器本地（localStorage），无需注册、无需联网、无需安装任何东西。

> 仓库地址：https://github.com/xheng-cs/campus-gpa-helper （推送到 GitHub 后生效）
>
> 本项目完整走了一遍「想法 → AI 开发 → 调试 → Git 提交 → 完成交付」的流程：
> 设计文档见 [PLAN.md](./PLAN.md)，面试准备手册见 [docs/INTERVIEW.md](./docs/INTERVIEW.md)。

## ✨ 功能

- 🧮 **绩点计算**：4.0 分档制 / 5.0 连续制 两种算法一键切换
- 📝 **灵活的成绩输入**：百分制（92、88.5）或等级制（优秀/良好/中等/及格/不及格）
- 📚 **课程管理**：添加/删除课程，实时计算总学分、加权平均分与 GPA
- ✅ **作业待办**：截止日期、完成勾选，过期/今天/未来 自动高亮提醒
- 💾 **本地持久化**：刷新不丢数据；支持导出 JSON、一键载入示例数据
- 🌗 **深色模式**：自动跟随系统外观，移动端响应式

## 🧮 绩点算法说明

**4.0 分档制（默认，参考美式标准）**

| 分数区间 | 绩点 | 分数区间 | 绩点 |
| --- | --- | --- | --- |
| 90 – 100 | 4.0 | 72 – 74.9 | 2.3 |
| 85 – 89.9 | 3.7 | 68 – 71.9 | 2.0 |
| 82 – 84.9 | 3.3 | 64 – 67.9 | 1.7 |
| 78 – 81.9 | 3.0 | 60 – 63.9 | 1.0 |
| 75 – 77.9 | 2.7 | 0 – 59.9 | 0 |

**5.0 连续制**：绩点 = (分数 − 50) / 10，低于 60 分记 0（60 分对应 1.0，100 分对应 5.0）

**等级制映射**：优秀→95 · 良好→85 · 中等→75 · 及格→65 · 不及格→0

**总 GPA** = Σ(课程绩点 × 学分) ÷ Σ学分；**加权平均分** = Σ(分数 × 学分) ÷ Σ学分。

不同学校的算法可能不同，映射表集中在 `js/gpa.js` 顶部，改一行即可适配。

## 🛠 技术栈与设计取舍

- **原生 HTML / CSS / JavaScript**：零依赖、零构建，双击即可运行，也最适合理解浏览器底层
- **为什么不用 ES Modules**：模块脚本在 `file://` 下会被浏览器 CORS 拦截；为了「双击即用」，采用经典脚本 + `window.GPA` 命名空间，同时兼容 Node `require`（UMD-lite）
- **纯函数核心与 UI 分离**：计算逻辑不碰 DOM，因此可以在 Node 里直接单元测试
- **Node 内置 test runner**：不需要安装 Jest 等依赖
- **GitHub Actions**：push 即自动测试，养成 CI 习惯
